### 🟡 PM-230：官網 /features 新增「MCP 工作流」區塊（單 Agent / 雙 Agent / 多工具）

**背景**：BugEzy MCP 可以同時被多個 AI client 連線讀取同一份報告，這是核心賣點但官網沒說明。需要在 /features 頁新增一個區塊展示不同工作流。

**在 /features 頁新增 §10 區塊（放在 §9 定價之前）：**

**區塊標題（中）**：MCP 工作流 — 錄一次，所有 AI 都能讀
**區塊標題（英）**：MCP Workflows — Record Once, Every AI Can Read

**內容三欄並排：**

**① 單 Agent 工作流（中/英）**
- 標題（中）：🤖 一個 AI 搞定
- 標題（英）：🤖 Single Agent
- 說明（中）：用 Claude Desktop、Cursor 或 Windsurf，連上 BugEzy MCP，直接讀報告修 Bug。一個 AI 從頭做到尾。
- 說明（英）：Connect Claude Desktop, Cursor, or Windsurf to BugEzy MCP. One AI reads the report and fixes the bug end-to-end.

**② 雙 Agent 工作流（中/英）**
- 標題（中）：🤝 兩個 AI 分工
- 標題（英）：🤝 Dual Agent
- 說明（中）：Claude Chat 讀報告做分析和策略規劃，Claude Code 讀同一份報告寫修復程式碼。PM 和工程師各司其職，讀的是同一份 Bug 報告。
- 說明（英）：Claude Chat reads the report for analysis and planning. Claude Code reads the same report to write the fix. PM and engineer roles, same bug report.

**③ 多工具工作流（中/英）**
- 標題（中）：🔗 多工具同步
- 標題（英）：🔗 Multi-Tool Sync
- 說明（中）：Zed、Cursor、Claude Desktop 同時連線 BugEzy MCP，都讀同一份報告。團隊成員用不同工具，看到的是同一份 Bug 資料。
- 說明（英）：Zed, Cursor, Claude Desktop — all connected to BugEzy MCP at the same time, all reading the same report. Different tools, same bug data.

**三欄下方加一個 MCP 連線設定範例框：**

標題（中）：一行連線，任何 MCP 工具都能用
標題（英）：One line to connect, works with any MCP client

```json
{
  "mcpServers": {
    "bugezy": {
      "url": "https://bugezy.dev/mcp"
    }
  }
```

小字（中）：支援 Claude Desktop · Claude Code · Cursor · Windsurf · Zed · 任何 MCP 相容工具
小字（英）：Works with Claude Desktop · Claude Code · Cursor · Windsurf · Zed · Any MCP-compatible client
