### 🟡 PM-231：官網預設語言改為 Accept-Language 自動偵測（中文優先）

**背景**：FB 廣告投放台灣用戶，點進 bugezy.dev 看到英文版，直接跳出。$7 USD 廣告費全浪費。根因是官網預設顯示英文，沒有根據瀏覽器語言自動切換。

**目前行為**：
- `bugezy.dev/` → 預設英文
- `bugezy.dev/?lang=zh` → 中文
- 使用者需要手動加 `?lang=zh` 才看到中文

**改成**：
- 讀取 request header `Accept-Language`
- 如果包含 `zh`（zh-TW / zh-HK / zh-CN / zh）→ 自動顯示中文版
- 如果包含 `ja` → 日文（未來）
- 如果包含 `ko` → 韓文（未來）
- 其他全部 → 英文
- `?lang=` 參數仍然有效，手動指定優先於 Accept-Language

**改動位置**：`server/src/index.ts` 的 `getLang()` 或 HTML 頁面生成的語言判斷邏輯。

**具體邏輯**：
```
1. 檢查 URL 有沒有 ?lang= 參數 → 有就用它
2. 沒有 → 讀 Accept-Language header
3. Accept-Language 包含 zh → return 'zh'
4. 否則 → return 'en'（預設）
```

**影響範圍**：所有 HTML 頁面（首頁 / features / changelog / faq / skill / install / guide / privacy / feedback / reports）

**驗收條件**：
1. 用繁體中文瀏覽器開 `bugezy.dev/` → 自動顯示中文
2. 用英文瀏覽器開 `bugezy.dev/` → 顯示英文
3. `bugezy.dev/?lang=en` 強制英文（即使瀏覽器是中文）
4. `bugezy.dev/?lang=zh` 強制中文（即使瀏覽器是英文）
5. deploy 後 curl 測試：`curl -H "Accept-Language: zh-TW" https://bugezy.dev/ | grep '遇到'`

完成後在下方寫 `🔵 DONE-231` + deploy hash。

## 🔵 DONE-231 — Claude Code 回報（2026-07-14）

**官網預設語言改為 Accept-Language 自動偵測（中文優先）** — 純 server（`server/src/index.ts` `detectLang`）。

### 根因
- `getLang()` 本就有呼叫 `detectLang()` 讀 Accept-Language，但 `detectLang` 只檢查 **`accept.split(',')[0]`（第一段）** 是否含 zh。台灣用戶若瀏覽器 Accept-Language 為 `en-US,en;q=0.9,zh-TW;q=0.8`（en 為主但含 zh）→ 第一段是 en → 誤判英文 → FB 廣告點進看到英文即跳出。

### 改動（1 行邏輯）
- `detectLang`：`/zh/i.test(accept.split(',')[0])` → **`/zh/i.test(accept)`**（整個 Accept-Language 只要**包含** zh〔zh-TW/zh-HK/zh-CN/zh-Hant…〕就回 `'zh'`，不限第一順位；其餘英文；日韓 UI 未做暫歸英文）。
- `?lang=` 手動指定仍優先（`getLang` 先看 query param，不動）。全 10 個 HTML 頁皆經 `getLang` → 一併生效。

### 驗收（線上實測 `bugezy.dev`，deploy `4a911d49`）
1. `Accept-Language: zh-TW,...` → **中文**（首頁「遇到 Bug…」）✅
2. `Accept-Language: en-US,en` → **English**（"Can't explain…"）✅
3. `?lang=en`（即使 zh 瀏覽器）→ 強制英文 ✅
4. `?lang=zh`（即使 en 瀏覽器）→ 強制中文 ✅
5. **`en-US,en;q=0.9,zh-TW;q=0.8`（en 主但含 zh）→ 中文**（本次修復的核心 case）✅；`en-GB,zh-CN;q=0.7` 亦中文 ✅
6. `curl -H "Accept-Language: zh-TW" https://bugezy.dev/ | grep '遇到'` → 命中 ✅

### 註記
- 首頁及各對外頁皆 `Cache-Control: no-store`，每次請求即時跑 `getLang`，不受邊緣快取影響（無 Accept-Language 混語問題）。

### Deploy
- `tsc --noEmit` clean → `wrangler deploy` Version `4a911d49`（cron 保留）。
