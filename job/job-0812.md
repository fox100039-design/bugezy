### 🟡 PM-286：移除未使用的 scripting 權限 + 重新打包

**問題**：v1.1.5 被 Chrome Web Store 拒絕，原因「要求但未使用 scripting 權限」。掃描確認整個 codebase 無任何 `chrome.scripting` 呼叫。

**修法**：

1. `extension/manifest.json` 第 7 行，permissions 移除 `"scripting"`：
   ```json
   "permissions": ["activeTab", "storage", "downloads", "identity", "offscreen"]
   ```

2. `npm run build`

3. 重新打包 zip：
   ```bash
   cd extension/dist && zip -r ../bugezy-v1.1.5.zip .
   ```

4. 確認 zip 內 manifest.json 不含 scripting

**驗收條件**：
1. manifest.json permissions 無 `scripting`
2. `npm run build` 成功
3. `bugezy-v1.1.5.zip` 已重新產出
4. `tsc --noEmit` 通過

完成後在下方寫 `🔵 DONE-286`。

**改動檔案**：只改 `extension/manifest.json`（一行）。`tsc --noEmit` 零錯誤、`npm run build` 成功、`bugezy-v1.1.5.zip` 已重新產出。

           → ["activeTab", "storage", "downloads", "identity", "offscreen"]

---

#### 先自行驗證，而不是直接照改

掃過 `extension/src`、`extension/dist`、`cli`、`mcp-server`：

- **`chrome.scripting`：0 次命中**（原始碼與產物皆是）
- 再擴大掃 `executeScript` / `insertCSS` / `registerContentScripts` / `removeCSS` / `unregisterContentScripts` → **同樣 0 次**
- 原因很清楚：兩個 content script 都是 **manifest 宣告式注入**（`content.js` ISOLATED、`inject.js` MAIN，皆在 `content_scripts` 宣告），這條路徑本來就不需要 `scripting` 權限。

→ 移除是安全的，不會有任何功能失去注入能力。

#### 順手做的事：把其餘 5 個權限也逐一驗過

既然已經被退件一次，只確認 `scripting` 而讓另一個未使用權限留著，就會再被退一次。逐一查證結果**全部都有實際使用**：

| 權限 | 實際用途 |
|---|---|
| `activeTab` | `chrome.tabs.query({active:true})`（background.ts:136）、`chrome.tabs.captureVisibleTab`（:274 截圖） |
| `storage` | 112 處（設定、session token、票券狀態、語言…） |
| `downloads` | `chrome.downloads.download`（popup.ts:648，JSON 匯出） |
| `identity` | `chrome.identity.getAuthToken`（popup.ts:675 Google 登入）、`clearAllCachedAuthTokens`（:1451 登出） |
| `offscreen` | `chrome.offscreen.createDocument`（background.ts:398，Whisper 錄音） |

另注意：程式有 10 處 `chrome.tabs.create`，但**不需要宣告 `tabs` 權限**（建立分頁不需要，只有讀取分頁 URL/標題才需要），目前也確實沒宣告——沒有「多宣告」的問題。

#### 打包沒用卡片的 `zip -r .`

卡片寫 `cd extension/dist && zip -r ../bugezy-v1.1.5.zip .`，這會把 **build 遞迴帶進 `dist/` 的 7 個設計原稿**（`icons/proposals/` 六個 icon 提案 + `icon-source.svg`）一起打包（PM-251/283 已處理過同一件事，ARCHITECTURE §4-12 也記著）。仍照既有做法排除。
